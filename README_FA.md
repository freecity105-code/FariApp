# مکتبه کامله فارسی

نسخه فعلی یک کتابخانه فارسی اندرویدی با رابط راست‌به‌چپ است.

امکانات موجود:
- کتابخانه و دسته‌بندی
- جست‌وجو
- مطالعه متن
- علاقه‌مندی‌ها
- یادداشت‌ها
- ادامه مطالعه
- وارد کردن فایل TXT
- گفتار به متن فارسی
- اشتراک‌گذاری
- تنظیم اندازه متن
- ساخت APK و AAB با GitHub Actions

محتوای دارای حق‌نشر فقط باید با مجوز یا از منابع آزاد وارد برنامه شود.
